# 混剪素材整理助手：当前范围

用户于 2026-09-28 重新明确需求。本文件优先于旧版 ARCHITECTURE.md、ACCEPTANCE.md 和原 Phase 1–8 计划。

核心改名功能：

1. 选择本地文件夹，软件打开期间每两秒检查一次；新视频大小和修改时间稳定至少两秒后，自动改成 `YYYY-MM-DD_HH-mm-ss.扩展名`。同一秒重名时补 `_001`、`_002` 等，绝不覆盖原有文件。
2. 从列表选中一个视频，填写非负整数次数并保存，实际文件改成 `原日期时间_使用次数：N.扩展名`。这是直接设定次数，允许从 5 改回 2；日期时间不会重新生成。

选择文件夹时，其中已有的未管理视频也会按上述规则处理。支持 MP4、MOV、M4V、AVI、MKV，包括子文件夹。保留视频内容和扩展名（统一为小写）。同一秒的防重序号会随使用次数修改保留。

时间来自本机时区和系统时钟；格式中的时分秒用连字符，次数后的冒号用中文全角冒号，因为 Windows 文件名不支持英文冒号。

界面提供目录选择、带首帧缩略图的视频列表、次数输入与保存；自动扫描不需要点击“重新扫描”。缩略图按需读取并缓存在本机，解码失败时显示默认图标，不改变原视频。每页 100 个视频；翻页可选择更多视频。关闭软件即停止监听；下次打开会处理期间新增的视频。

必要保护继续保留：复制完成检测、禁止覆盖、文件身份和指纹复核、界面防重复提交、数据库事务、改名操作日志、启动恢复、中文错误提示及本机日志。升级数据库前备份。数据库从旧版 schema=2 迁移到 schema=3，旧表与历史保留。
